CleanUp Manager

Import iCal (réservations)
Objectif : importer les réservations (Airbnb / Booking / autres plateformes) pour alimenter le planning.
Important : seul le compte conciergerie peut importer.
Colle le lien iCal du logement.
👉 Le lien doit commencer par https://
👉 CleanUp n'accepte pas les fichiers.ics pour la synchronisation automatique.
Comment récupérer le bon lien iCal ?
  • Airbnb : Annonce → Disponibilité / Calendrier → Synchroniser les calendriers → Exporter le calendrier → copier le lien iCal
  • Booking : Extranet → Calendrier / Tarifs et disponibilités → Synchronisation calendrier → Exporter → copier le lien iCal
  • Le bon lien est un lien internet qui commence par https:// ou parfois webcal://
  • CleanUp n'accepte pas les fichiers .ics, pour la synchronisation automatique.
