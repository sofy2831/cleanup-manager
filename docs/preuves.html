Android / Samsung (ex. S25 Ultra) : créer un ZIP
  • Fais tes photos.
  • Ouvre Mes Fichiers (ou “Fichiers”). Va dans Récents.
  • Sélectionne 10/15/20 photos.
  • Menu ⋮ (3 points) → Compresser.
  • Renomme le fichier : un .zip apparaît, prêt à uploader ici.
iPhone : créer un ZIP
  • Ouvre l’app Fichiers.
  • Va dans le dossier où sont tes photos (ou enregistre-les d’abord dans Fichiers).
  • Sélectionne 10/15/20 photos.
  • Bouton ⋯ → Compresser.
  • Le fichier .zip apparaît : upload-le ici.
Mission
Les photos ne sont pas obligatoires pour terminer.
Firestore : events/{prestationId}/missions/{TYPE}.proofZip
Storage : proofZips/{prestationId}/{TYPE}/{token}/{file}.zip
