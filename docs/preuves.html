Preuves photos (ZIP)

Chargement…
Envoie un seul fichier ZIP (10/15/20 photos). C’est plus fiable que photo par photo.
Upload…
Android / Samsung : créer un ZIP
  • Fais tes photos.
  • Ouvre Mes Fichiers → Récents.
  • Sélectionne 10/15/20 photos.
  • Menu ⋮ → Compresser.
  • Renomme : un .zip apparaît, prêt à uploader.
iPhone : créer un ZIP
  • Ouvre l’app Fichiers.
  • Place tes photos dans Fichiers (si besoin), puis sélectionne-les.
  • Bouton ⋯ → Compresser.
  • Le fichier .zip apparaît : upload-le ici.
