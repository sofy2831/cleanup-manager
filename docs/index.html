Démarrage guidé (conciergerie)
  1. Créer un compte conciergerie (email + mot de passe).
  2. Compléter ton profil conciergerie (infos de base + facturation).
  3. Choisir ton abonnement : gratuit pour 0–2 logements, au-delà abonnement.
  4. Inviter les propriétaires : ils accèdent à leur espace gratuitement — zéro commission.
