Politique de confidentialité

Dernière mise à jour : mars 2026

CleanUp Manager est une solution SaaS destinée aux professionnels. Cette politique explique comment les données sont traitées et protégées.

1. Rôles RGPD

  • Conciergerie : responsable de traitement
  • CleanUp Manager : sous-traitant technique

2. Données collectées

  • Compte utilisateur (email, société, paramètres)
  • Données métier (logements, clients, agents, factures)
  • Photos et preuves
  • Données techniques (logs, sécurité)

3. Finalités

  • Fournir le service
  • Gérer les abonnements
  • Sécuriser la plateforme
  • Améliorer les performances

4. Paiement

Les paiements sont traités via Stripe. CleanUp Manager ne stocke pas les données bancaires.

5. Hébergement

Les données sont hébergées via Google Cloud / Firebase. Des transferts hors UE peuvent exister, encadrés par des garanties contractuelles (clauses types).

6. Conservation

  • Données compte : durée du compte
  • Données métier : selon usage client
  • Facturation : obligations légales

7. Sécurité

Mesures mises en place : authentification, règles Firestore, chiffrement en transit.

8. Partage

Aucune vente de données. Partage uniquement :

  • utilisateurs autorisés
  • prestataires techniques
  • obligations légales

9. Droits

Accès, rectification, suppression, portabilité. Les demandes clients passent par la conciergerie responsable.

10. Cookies

Uniquement cookies techniques nécessaires au fonctionnement.
